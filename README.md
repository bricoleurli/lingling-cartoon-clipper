# 卡通形象快存

这是卡通工作台的本地 Chrome 扩展。它截取网页中实际显示的图片区域，压缩成 WebP 文件，保存到电脑的 `下载/卡通形象快存/<分类>/`。后台没有打开、尚未登录或网络暂时不可用时，图片进入待上传队列；以后打开并登录管理员后台会自动补传为种子形象。本地文件始终保留。

当前版本：`0.4.0`

## 从 GitHub 安装

1. 打开 [Releases 下载页](https://github.com/bricoleurli/lingling-cartoon-clipper/releases/latest)，下载 `lingling-cartoon-clipper-v0.4.0.zip`。
2. 解压 ZIP；不要直接在压缩包里打开文件。
3. 在 Chrome 地址栏输入 `chrome://extensions`。
4. 打开右上角“开发者模式”，点击“加载已解压的扩展程序”。
5. 选择解压后、包含 `manifest.json` 的 `lingling-cartoon-clipper` 文件夹。
6. 在 Chrome 右上角的扩展菜单中，把“卡通形象快存”固定到工具栏。

保存到灵凌星球还需要使用者在同一个 Chrome 里登录获得授权的 `xhs.typoai.xin` 管理员账号。没有登录或没有权限时，图片仍会保存到电脑本地并进入待上传队列；以后登录后台会自动补传。扩展不包含共享密码或隐藏管理员凭据。

## 使用方式

1. 在 Chrome 打开 `chrome://extensions`，开启右上角“开发者模式”。
2. 点“加载已解压的扩展程序”，选择本目录。
3. 点插件图标，在“以后默认保存到”里选择分类。分类会一直保留，直到再次修改；点“同步”可以读取工作台管理员创建的最新分类。
4. 可选开启“鼠标悬停时显示快存浮标”。首次开启时 Chrome 会申请“读取和更改所有网站上的数据”权限，请点击“允许”。这个可选权限同时用于网页内悬停截图；不开启悬停时不会申请，关闭开关后会立即移除。
5. 点“点选网页里的图片”可保存整张网页图片；点“框选网页区域”后按住鼠标拖框，可只保存画面中的局部。框选时按 `Esc` 取消。
6. 鼠标悬停浮标的确认框里也有“框选局部”，适合先找到目标图片，再只截其中需要的形象。
7. 也可以在网页图片上点右键，选择“保存到卡通工作台”。
8. 图片一定先保存为本地文件。后台已登录时同时自动上传；未打开后台、未登录或网络不可用时会显示待上传数量。以后打开并登录后台会自动补传，也可在插件里点“立即补传”。

## 实际行为

- 只截取屏幕上看得到的区域，不下载原图，不读取图片网站的登录凭据。
- 输出 WebP，最长边不超过 1400 像素，质量 82%，足够辨认角色并减少存储和上传时间。
- 截图前临时隐藏插件自己的“快存”浮标、确认框和提示条，避免这些界面进入结果图。
- 默认名称依次使用图片说明、图片标题、图片文件名、网页标题；末尾加 `月日-时分`，避免连续收图时名称重复。
- 分类来自卡通工作台管理员创建的分类列表，插件里只做选择，避免出现名称相近的重复分类。
- 框选工具只处理当前屏幕可见区域。松开鼠标后会先移除遮罩，再进入同一套 WebP 压缩、本地保存和后台自动上传流程；拖框过小时只显示一次中文提示，不会保存空图。
- 从图片浮标进入“框选局部”时，如果框选范围完整落在同一张已确认的大图中，插件会在截图瞬间用这张图片的干净克隆盖住 Pinterest 自带的“保存”等悬停控件。截图成功或失败后都会立即移除克隆并恢复页面。
- 干净克隆只用于位置、地址和样式都能唯一确认的普通 `<img>`。普通网页区域、背景图、跨出图片的框选、重复候选或复杂变换会保持网页原样，避免误改截图内容。
- 分类直接成为本地子文件夹。永久文件在电脑的下载目录；为实现登录后的自动补传，尚未上传的 WebP 会额外暂存在 Chrome 扩展专属的 IndexedDB 队列里，成功上传后立即从队列删除。Chrome 设置区只保存默认分类、最近文件位置、待上传数量和上传状态等少量信息。
- 文件重名时 Chrome 自动添加编号，不覆盖旧文件；上传成功后本地文件仍然保留。
- 插件图标上的橙色数字是待上传数量。后台标签页加载完成、切回后台标签页或 Chrome 启动时都会尝试补传；没有登录时不会丢图，也不会从队列删除。
- 扩展只固定访问 `https://xhs.typoai.xin`；浏览其他网页时只在用户右键或点选后临时获得当前标签页权限。
- 悬停浮标默认关闭。只有用户主动开启并接受 Chrome 的可选网页访问权限后，扩展才会在普通 HTTP/HTTPS 网页里监听图片悬停并截取当前可见区域；不会注入卡通工作台后台页面。
- 网页按钮或透明遮罩盖在图片上时，插件会继续检查鼠标位置下方的底层大图；小于 90×90 像素的图标不会触发“快存”。`picture/source` 和常见 CSS 背景图也可识别。
- Chrome 自带的权限、下载和截图错误会转换成中文提示。一次保存失败后确认框会关闭，不会自动重试或反复弹出。

## 更新后重新加载

在 `chrome://extensions` 找到“卡通形象快存”，点击卡片上的重新加载按钮，再刷新原来的网页。`0.4.0` 新增可靠的待上传队列、自动补传、待上传角标和“立即补传”；也继续保留符合条件的图片局部框选清除 Pinterest 自带悬停控件，以及“保存整张”和“框选局部”入口。若悬停开关没有开启，重新开启并在 Chrome 权限提示里点击“允许”。

## 当前限制

- 页面里的图片如果只显示了一部分，只会保存可见部分。
- 浏览器内部页面（例如 `chrome://`）不允许扩展点选或框选。
- 当前不在本地图片旁额外生成来源说明文件，也不把素材来源写入后台数据库。

## 隐私与开源

扩展不含广告、访问统计或第三方跟踪。只有在使用者主动点击保存时才会生成截图；尚未上传的截图只在本机扩展队列中等待，已登录且获得后台权限后上传到 `https://xhs.typoai.xin`。详见 [PRIVACY.md](PRIVACY.md)。
